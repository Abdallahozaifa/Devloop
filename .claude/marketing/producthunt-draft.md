## Description (300 words)

### The Problem

Manual testing is the worst part of shipping software.

Most indie hackers skip it because:
- It's boring and repetitive
- It takes time away from building features
- There's always "more important" work to do

The result? Bugs slip into production. Users find them first. Your reputation takes a hit.

### The Solution

DevLoop automates your entire QA workflow with one command:

```bash
npx create-devloop
```

That's it. In 2 minutes, you have a complete QA system that:

**API Smoke Testing**
- Tests every endpoint automatically
- Validates response codes and schemas
- Measures response times
- Catches breaking changes before users do

**UI Screenshot Testing**
- Captures your app at 3 viewports (desktop, tablet, mobile)
- AI vision analysis detects broken layouts
- Visual regression detection
- No Selenium nightmares

**Production Monitoring**
- Continuous health checks
- Response time tracking
- Instant Slack alerts when something breaks
- Sleep peacefully knowing your app is watched

**CI/CD Integration**
- GitHub Actions workflow included
- Runs on every push/PR
- Blocks broken code from shipping

### Why We Built This

We're indie hackers too. We couldn't afford $500/mo enterprise testing tools, but we were tired of shipping bugs.

DevLoop is enterprise-grade QA at indie hacker prices.

### Pricing

- **Solo**: $19/mo (1 project)
- **Pro**: $39/mo (5 projects)
- **Team**: $79/mo (unlimited)

Less than your coffee habit. More confidence in every deploy.
